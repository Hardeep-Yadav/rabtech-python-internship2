# Automated Web Scraping & Data Extraction Pipeline

## Project Overview

This project is an automated web scraping pipeline developed using Python.

The scraper collects publicly available book information from Books to Scrape and converts the extracted HTML data into structured CSV format.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV
- Statistics

## Features

- Automated web scraping
- Custom HTTP headers
- Request timeout
- Retry logic
- Rate limiting
- HTML parsing
- Data cleaning
- CSV data extraction
- Automated summary statistics
- Price analysis
- Rating distribution
- Availability statistics

## Data Collected

The scraper collects:

- Book title
- Price
- Rating
- Availability
- Product URL
